║                    ⚠️  TROUBLESHOOTING                           ║
╚══════════════════════════════════════════════════════════════════╝

   ❌ If you see: "pytest module not found"
   → Run: pip install pytest
   → Restart backend
   
   ❌ If you see: "Rate limit hit" (every call)
   → Backend needs restart (rate limit fix not applied)
   → Stop backend (Ctrl+C) and run setup_and_run.bat again
   
   ❌ If you see: "Tests: 0/0"
   → Check pytest is installed: python -m pytest --version
   → Run diagnostic: python debug_test_generation.py
   
   ❌ If you see: "GitHub API error"
   → Check .env has GITHUB_TOKEN
   → Check repository name is correct
