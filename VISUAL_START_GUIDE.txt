┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: OPEN FIRST TERMINAL (Backend)                                        │
└───────────────────────────────────────────────────────────────────────────────┘

  1. Open Command Prompt or PowerShell
  2. Navigate to project:
  
     cd D:\Jira-Agentic-Development-System
  
  3. Activate virtual environment:
  
     venv\Scripts\activate
  
     You should see: (venv) in your prompt
  
  4. Start backend:
  
     python backend\main.py
  
  5. Wait for this message:
  
     ✅ INFO:     Uvicorn running on http://0.0.0.0:8000
  
  6. ⚠️  KEEP THIS TERMINAL OPEN! Don't close it!


┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: OPEN SECOND TERMINAL (Frontend)                                      │
└───────────────────────────────────────────────────────────────────────────────┘

  1. Open a NEW Command Prompt or PowerShell
  2. Navigate to frontend:
  
     cd D:\Jira-Agentic-Development-System\frontend
  
  3. Start frontend:
  
     npm run dev
  
  4. Wait for this message:
  
     ✅ Local:   http://localhost:5173/
  
  5. ⚠️  KEEP THIS TERMINAL OPEN TOO!


┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: OPEN BROWSER                                                          │
└───────────────────────────────────────────────────────────────────────────────┘

  1. Open your web browser (Chrome, Firefox, Edge)
  2. Go to:
  
     http://localhost:5173
  
  3. You should see the frontend application!


┌───────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: VERIFY CONNECTION                                                     │
└───────────────────────────────────────────────────────────────────────────────┘

  ✅ Check 1: Frontend loads in browser
  ✅ Check 2: No errors in browser console (Press F12)
  ✅ Check 3: Backend terminal shows no errors
  ✅ Check 4: Try a test action in the UI

┌───────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                                │
└───────────────────────────────────────────────────────────────────────────────┘

  ❌ Problem: Backend won't start
  ✅ Solution:
     venv\Scripts\activate
     pip install -r requirements.txt
     python backend\main.py

  ❌ Problem: Frontend won't start
  ✅ Solution:
     cd frontend
     npm install
     npm run dev

  ❌ Problem: "Port already in use"
  ✅ Solution:
     netstat -ano | findstr :8000
     taskkill /PID <PID> /F

  ❌ Problem: CORS errors in browser console
  ✅ Solution: Backend is configured for port 5173
     Check backend/main.py CORS settings

  ❌ Problem: Frontend shows "Network Error"
  ✅ Solution:
     1. Check backend is running (Terminal 1)
     2. Check backend is on port 8000
     3. Check frontend is trying to connect to http://localhost:8000
